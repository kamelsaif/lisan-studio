# Lisan Studio · لسان

**ارفع فيديو بالإنجليزي، وشاهد وحمّل نسخة مدبلجة بالعربي.**

لسان مشروع مفتوح المصدر بواجهة عربية وإنجليزية. يرسل الفيديو إلى ElevenLabs لتوليد الدبلجة العربية، ثم يدمج الصوت الجديد مع الفيديو الأصلي على جهازك.

**الكود متاح للاستخدام والتعديل بترخيص MIT. تشغيل الدبلجة يحتاج مفتاح API خاص بك من ElevenLabs، وصلاحية Dubbing، ورصيدًا كافيًا، واتصالًا بالإنترنت. الفيديو يُرفع إلى ElevenLabs أثناء الدبلجة.**

## التشغيل على الماك

1. ثبّت **Node.js بإصدار 22 أو أحدث** من [الموقع الرسمي](https://nodejs.org/).
2. [حمّل نسخة المشروع ZIP](https://github.com/kamelsaif/lisan-studio/archive/refs/heads/main.zip) وفك الضغط.
3. افتح ملف **Open Lisan Studio.command** داخل مجلد المشروع. التشغيل الأول يثبّت المكتبات ويجهّز التطبيق. احتفظ بملفات المجلد معًا.
4. التطبيق يفتح في المتصفح على **http://127.0.0.1:4317**. يمكنك إغلاق نافذة التشغيل بعد فتحه.

لو ملف التشغيل فتح كنص أو لم يكن قابلًا للتنفيذ، افتح Terminal داخل مجلد المشروع وشغّل:

```sh
chmod +x "Open Lisan Studio.command" "Stop Lisan Studio.command"
./"Open Lisan Studio.command"
```

لإغلاق التطبيق، افتح **Stop Lisan Studio.command** بعد انتهاء الدبلجة. إغلاق المتصفح وحده يترك التطبيق يعمل حتى يكمل المهمة.

## التشغيل من Terminal

```sh
git clone https://github.com/kamelsaif/lisan-studio.git
cd lisan-studio
npm ci
npm start
```

افتح **http://127.0.0.1:4317**. أمر `npm start` يجهّز السيرفر ثم يشغّله. استخدم **Ctrl+C** لإيقافه بعد انتهاء المهمة.

الماك هو نظام التشغيل الذي جُرّب عليه التطبيق. أوامر Terminal تعتمد على دعم Node.js ومكتبات FFmpeg وFFprobe لنظامك؛ نجاح التثبيت على نظام آخر لا يضمن دعم كل صيغة فيديو.

## استخدام التطبيق

1. افتح **الاتصال**، وأدخل مفتاح ElevenLabs الخاص بك مع صلاحيات الدبلجة. [دليل المفاتيح الرسمي](https://elevenlabs.io/docs/api-reference/authentication).
2. اختر حفظ المفتاح على جهازك إن أردت، ثم اتصل.
3. اسحب الفيديو أو اختره من جهازك. يمكنك استخدام فيديو العينة الإنجليزي المرفق، ومدته 20 ثانية.
4. شاهد الأصل، واكتب اسمًا للفيديو، وأضف أسماء أو مصطلحات قصيرة عند الحاجة.
5. وافق على رفع الفيديو واستخدام رصيد حسابك، ثم اضغط **دبلج للعربية**.
6. تابع حالة المعالجة، وقارن النسختين، وحمّل MP4 أو WAV. النص المترجم وملف SRT يظهران عندما يوفرهما ElevenLabs.

اكتملت تجربة فعلية لعينة إنجليزية مدتها 20 ثانية، مع دبلجة عربية وتصدير MP4 وWAV وSRT على الماك أثناء تطوير المشروع. راجع المعنى والنطق وتطابق الصوت والتوقيت في كل نتيجة قبل نشرها.

## الخصوصية والحدود

- الصيغ المقبولة: MP4 وMOV وWEBM وMKV وM4V وAVI، حتى 3 GiB، بشرط وجود فيديو وصوت قابلين للقراءة.
- الدبلجة من الإنجليزية إلى العربية (`ar`)، دون ضمان لهجة إقليمية معينة.
- الملفات والنتائج وسجل المشاريع تُحفظ محليًا في `data/jobs/`. الدبلجة نفسها تتم على خدمة ElevenLabs.
- المفتاح المحفوظ يوجد في `data/connection.json` بصلاحيات ملف مقيدة على الماك ولينكس، ولكنه غير مشفّر. زر **فصل الاتصال وحذف المفتاح** يحذفه.
- المفتاح يُرسل من الواجهة المحلية إلى السيرفر المحلي للتحقق منه. لا تعيده واجهات بيانات المشاريع، ولا يُخزّن في التخزين المحلي للمتصفح.
- السيرفر يعمل على `127.0.0.1` للاستخدام المحلي. لا تحوّله إلى موقع عام دون تصميم حماية مناسب.
- استخدم فيديوهات لديك حق رفعها ودبلجتها. حدود خطة ElevenLabs والرصيد والصيغ والخدمة تظل سارية.
- يحتفظ التصدير بمدة الفيديو الأصلي. يُضاف صمت للصوت الأقصر، ويُقص الصوت الذي يتجاوز نهاية الفيديو.
- التطبيق لا يترجم الكتابة الموجودة داخل الصورة، ولا يعدّل حركة الشفاه. الترجمة ملف SRT مستقل.

لا ترفع `data/` أو مفاتيح API أو ملفات `.env` أو السجلات أو فيديوهاتك الخاصة إلى GitHub. ملف `.gitignore` يستبعدها. المكتبات المثبّتة وملفات السيرفر المولّدة تُجهّز على جهاز كل مستخدم.

## لو الاتصال انقطع

أعد الاتصال ثم اختر **استكمال المشروع الحالي** عندما تكون المهمة مرتبطة بمشروع ElevenLabs معروف. الاستكمال يتحقق من نفس المشروع دون إنشاء دبلجة مدفوعة جديدة.

لو انقطع الرفع قبل استلام رقم المشروع، التطبيق يطلب مراجعة المهمة. راجع حساب ElevenLabs قبل إعادة الدبلجة؛ الطلب الأول ربما استهلك رصيدًا. التطبيق لا يعيد إنشاء الطلب المجهول تلقائيًا.

## للمطورين

```sh
npm ci
npm run check
npm test
npm start
```

الاختبارات تستخدم خدمة محلية وهمية وتصدير فيديو فعليًا عبر FFmpeg. لا تحتاج مفتاحًا ولا تستدعي توليد ElevenLabs ولا تستهلك رصيدًا. ملف الصوت المستخدم في الاختبار إنجليزي اصطناعي، وليس نتيجة عربية.

واجهة التطبيق في `public/`، والسيرفر في `server/`، وتجهيز التشغيل في `scripts/`، والاختبارات في `test/`. أمر `npm run build` يولّد `server/launch.mjs` و`server/core.mjs`.
